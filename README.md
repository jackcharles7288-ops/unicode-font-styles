## Why this exists

Most font generator apps lock their best styles behind a premium subscription. Text styling is just Unicode, it belongs to everyone. So this library gives the styles away as open source code: copy the file, use it in your own project, ship it in your app, sell your app if you like. MIT licensed, no strings.

Built by **Iris Labs**, the beginner-dev studio behind [Fonti](https://fonti.cool), a free generator with 350+ styles.

## Features

- **22 text styles**: Bold, Italic, Bold Italic, Script, Bold Script, Fraktur (Gothic), Bold Fraktur, Double-Struck, Monospace, Sans, Sans Bold, Sans Italic, Sans Bold Italic, Circled, Small Caps, Fullwidth, Squared, Black Squared, Parenthesized, Black Circled, Superscript, Subscript
- **`unstyle()` decoder built in**: fancy text back to plain text, generated by inverting the same tables, so the two directions can never drift apart
- **Honest metadata**: `listStyles()` reports exactly which letters and digits each style covers, and which ones Unicode simply does not have (there are no fraktur digits, no superscript Q, no subscript capitals, and this library says so instead of faking them)
- Light glitch (zalgo) generator, with zone control (`up` / `mid` / `down`) and `stripZalgo()` to undo it
- 8 layered effects: underline, double underline, strikethrough, slash, overline, enclosing circle, enclosing square, keycap
- 24 decorative name frames (꧁༺ 𝔫𝔞𝔪𝔢 ༻꧂ style)
- **Unlimited mode**: `combos()` mixes fonts, frames and effects into fresh styles on every call, the supply never runs out
- `upsideDown()` and `reverse()`, both grapheme-cluster safe: emoji sequences, flags and combining marks are never torn apart
- The tricky Letterlike exceptions (ℬ ℰ ℱ ℭ ℍ ℕ ℝ and friends) handled correctly, never the empty holes in the maths block
- Zero dependencies, one small file, works in the browser, in Node (CommonJS and ESM), with TypeScript types included
- Test suite included (`npm test`, Node's built-in runner, still zero dependencies)

## Usage

```js
// Browser: the script adds a global FontiStyles object
// Node:    const FontiStyles = require("unicode-font-styles");

FontiStyles.convert("Fonti", "boldScript");   // 𝓕𝓸𝓷𝓽𝓲
FontiStyles.convert("Fonti", "fraktur");      // 𝔉𝔬𝔫𝔱𝔦
FontiStyles.convert("Fonti", "circled");      // Ⓕⓞⓝⓣⓘ
FontiStyles.convert("Fonti", "smallCaps");    // ꜰᴏɴᴛɪ
FontiStyles.convert("tiny", "superscript");   // ᵗⁱⁿʸ
FontiStyles.convert("H2O", "subscript");      // H₂O

FontiStyles.unstyle("𝓕𝓸𝓷𝓽𝓲");              // Fonti
FontiStyles.unstyle("ʜᴇʟʟᴏ ᴡᴏʀʟᴅ");          // hello world (small caps lose case)

FontiStyles.zalgo("glitch me", 3);                              // light glitch text
FontiStyles.zalgo("glitch me", { intensity: 2, down: true });   // marks underneath only
FontiStyles.stripZalgo(FontiStyles.zalgo("clean me", 5));       // clean me

FontiStyles.effect(FontiStyles.convert("Fonti", "bold"), "underline");  // 𝐅̲𝐨̲𝐧̲𝐭̲𝐢̲
FontiStyles.frame(FontiStyles.convert("Nova", "fraktur"), 0);
// ꧁༺ 𝔑𝔬𝔳𝔞 ༻꧂

FontiStyles.upsideDown("Hello");              // ollǝH
FontiStyles.reverse("ab👨‍👩‍👧‍👦🇵🇰");           // 🇵🇰👨‍👩‍👧‍👦ba (emoji stay whole)

FontiStyles.combos("Nova", 24, 42);           // 24 fresh mixed styles, new seed = new styles, forever

FontiStyles.listStyles();
// [{ id: "fraktur", label: "Fraktur (Gothic)",
//    supports: { upper: true, lower: true, digits: false },
//    missing: "0123456789", notes: "Unicode has no fraktur digits..." }, ...]
```

## API

| Function | What it does |
|---|---|
| `convert(text, styleId)` | Plain text → styled Unicode text. Throws on an unknown style. |
| `unstyle(text)` | Fancy text → plain text. Handles every style here plus common generator output. |
| `zalgo(text, intensityOrOptions)` | Glitch text. A number keeps the classic behaviour; an options object `{ intensity, up, mid, down }` picks mark zones. |
| `stripZalgo(text)` | Removes combining marks and zero-width characters. Undoes zalgo and effects. |
| `effect(text, effectId)` | Layers a combining-mark effect (underline, strikethrough, circle, keycap, …) over text. |
| `frame(text, index)` | Wraps text in a decorative frame. |
| `spaced(text)` | Inserts hair spaces between characters. |
| `combos(text, count, seed)` | The unlimited engine: unique mixed combinations. Same seed, same output. |
| `upsideDown(text)` | Turned letters, reversed order, grapheme safe. |
| `reverse(text)` | Reverses by grapheme cluster, never by code unit. |
| `graphemes(text)` | Splits text into grapheme clusters. |
| `listStyles()` | All 22 styles with labels, coverage and honest gap metadata. |
| `getStyle(styleId)` | One style's metadata, or `null`. |

Raw data is exported too: `SETS`, `META`, `FRAMES`, `EFFECTS`, `SYMBOLS`, `UPSIDE_DOWN`, `VERSION`.

## What Unicode does not have (and this library will not fake)

Styled text is not fonts. Every style swaps a letter for a different Unicode character that happens to look styled, and for some combinations that character was never encoded:

- **Fraktur has no digits at all.** Neither does bold fraktur. Digits pass through unchanged; substituting double-struck digits, as some generators do, silently mixes two styles.
- **Superscript is missing** capitals C, F, Q, S, X, Y, Z and small q. **Subscript is missing** all capitals and the small letters b, c, d, f, g, q, w, y, z.
- **Small caps** are assembled from phonetic letters: Q borrows the lookalike ǫ, and there is no small capital X, so X stays a plain x.
- **Squared and black-squared** letters exist only as capitals; **black-circled** only as capitals too. Lowercase passes through.
- There is **no parenthesized zero**.

Instead of hiding this, `listStyles()` gives you `supports` and `missing` for every style, so your UI can warn users before they copy a half-styled name.

One more hard-won lesson, free of charge: almost all of these characters live outside the Basic Multilingual Plane, so each one is a surrogate pair in JavaScript and `"𝐚".length` is 2. Count code points (`Array.from(text).length`), or your character limits will lie to your users.

## Accessibility note

Screen readers announce many of these characters by their full Unicode names, or skip them entirely. Use styled text as decoration, never as the only copy of important information, and never for a name or hashtag that other people need to search for.
