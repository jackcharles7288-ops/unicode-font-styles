# Changelog

All notable changes to unicode-font-styles. This project follows semantic versioning.

## 1.0.0

### Added
- `unstyle(text)`: fancy text back to plain text. The reverse table is generated by inverting the encoder tables, so both directions stay in sync forever. Pipeline: reverse table, NFKD, combining-mark strip, reverse table. This folds small caps, superscripts and subscripts, which NFKD alone cannot do.
- 4 new styles, each verified character by character against the Unicode data files:
  - `parenthesized` (full A-Z, a-z, digits 1-9; there is no parenthesized zero)
  - `circledNegative` (capitals and digits; black-circled lowercase does not exist)
  - `superscript` (digits complete; capitals C F Q S X Y Z and small q do not exist)
  - `subscript` (digits complete; capitals and small b c d f g q w y z do not exist)
- Style metadata: `listStyles()` now returns `supports` ({ upper, lower, digits }) and `missing` (the exact source characters with no styled form) plus human-readable `notes` where a style has a story. New `getStyle(id)` and the `META` export.
- `upsideDown(text)` and `reverse(text)`, both grapheme-cluster safe (Intl.Segmenter with a code-point fallback). Emoji sequences, flags and combining marks are never torn apart.
- `zalgo(text, options)`: the options form `{ intensity, up, mid, down }` restricts marks to the chosen zones. The numeric form keeps the original behaviour exactly.
- `stripZalgo(text)`: removes combining marks and zero-width characters.
- 3 new effects: `circle` (U+20DD), `square` (U+20DE), `keycap` (U+20E3).
- npm packaging: `package.json` with a full exports map (types / import / require), `index.mjs` ESM wrapper with named exports, hand-written `index.d.ts` TypeScript definitions, `unpkg` / `jsdelivr` fields.
- Test suite in `test/` using Node's built-in runner (22 tests, still zero dependencies), including a byte-for-byte regression comparison against the 0.x file, roundtrip tests for every style, and grapheme-safety tests.

### Fixed
- **Small caps lowercase bug (0.x):** the 0.x repo file left lowercase letters completely unstyled in the smallCaps style (only capitals were converted). 1.0.0 styles both cases, matching the project's canonical mapping table.

### Notes
- `combos()` now draws from all 22 styles and 8 effects, so seeded output differs from 0.x. Everything else in the 0.x API (convert, zalgo numeric form, effect, frame, spaced, listStyles shape) is unchanged; listStyles entries gained fields but kept `id` and `label`.
- If the npm name `unicode-font-styles` is unavailable at publish time, the fallback is the scoped name `@irislabs/unicode-font-styles`; the API is identical either way.

## 0.x (single-file releases)

- 18 styles, light zalgo, 5 effects, 24 frames, the unlimited `combos()` engine, browser global + CommonJS, distributed via GitHub and the jsdelivr GitHub CDN.
